# Star-Finder
An astrological tracking laser device that is designed to be able to find and track stars, planets, and satellites as they move across the sky. This device utilizes two NEMA-17 stepper motors with magnetic encoders, one to move on the horizontal axis and the other to control the angle above the horizon. These motors are powered by two Closed Loop Stepper Driver (CL42T-V41) and hooked up to an Arduino Uno. To find each astrological object this device will utilize the python tool skyfield.api to find their altitude and Azimuth, next it will use python to control the motors using pySerial to send over necessary data to the Arduino.
